# Reference files

Put a **copy** of your DAR workbook here as `MABANO_DAR_sample.xlsx`. Never the live one.

Phase 1 seeds the database from its "October 3 - 17" sheet, and Phases 1-2 test against it. Exports before Phase 8 go to a copy of this file, never to your real workbook.

This folder's `.xlsx` files are git-ignored, since the workbook has your name and work details in it.
